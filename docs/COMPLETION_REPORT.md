## 与上游完整制作标准的区别

本版交付七章交互课程、首页双语导论片及每章一部原创双语课时影片，保留原作者影片。没有制作上游标准中的每章四部全新双语影片、原生 PDF/PPTX 课件，也未达到其长篇讲义字数目标；网页讲义可打印保存 PDF，原作者已提供的课件仍可下载。没有把这些进一步制作项声称为完成。

首页与七章新片包含在离线包中。原作视频与课件仍由作者站点提供，离线包不包含这些外部媒体；若作者移动文件，需更新链接。所有真实实验、讲义、搜索与 Python 运行时保存在本地。学习进度仅本地保存，无账号或云同步。
