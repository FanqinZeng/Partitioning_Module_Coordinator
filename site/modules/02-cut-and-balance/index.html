03 / BEFORE YOU READ

先认识这些词

把合作最密切的人分到两间办公室，会发生什么？

节点 / vertex

电路单元；带有正的面积 size。

边权 / weight

一次跨组连接的非负代价；本实验要求正权。

割代价 / cut

所有跨组无向边的权重之和，每条只算一次。

容量 / capacity

每个分组所容许的最大面积和。

可行 / feasible

满足完整分组、非空与规定容量。

01 · 从分组检查开始

芯片中的单元是节点，单元之间的连接是边。把单元分到不同区域后，跨区域连线会消耗布线资源。我们先用一个简化模型衡量这项代价：无向边的权重表示切开这条连接的成本。它不是完整的布线长度或时序模型，却能让我们明确比较同一模型下的分组。

一个二分必须让每个节点恰好出现一次，两侧都非空。漏掉 C、把 C 同时放进两侧、把所有节点都塞到左侧，都不是本课程接受的二分。检查输入和分组应先于计算指标；否则漏分的节点可能被当成一个新组，得到一个看似合理的错误数字。

公共图 G01 有 A、B、C、D、E 五个节点，边为 AB:5、AC:1、BC:4、CD:2、CE:1、DE:5。每条边只列一次，所有节点默认面积为 1。后面六章仍使用这张图，让算法的区别不被样例的变化掩盖。

02 · 一条边只算一次

割代价定义为 cut = Σ w(u,v)·[part(u) ≠ part(v)]。方括号在条件成立时为 1，否则为 0。判断依据是两端是否异组，不是这条线在屏幕上是否穿过某个框，也不是它是否与其他线相交。

把 AE 放左边、BCD 放右边，跨边为 AB、AC、CE、DE，cut = 5+1+1+5 = 12。请逐条复核：D 在右、E 在左，DE 跨组；C 在右、E 在左，CE 也跨组。CD 两端同在右侧，不应计入。逐边核对比凭图形印象凑出一个和更可靠。

改成 ABC | DE 后，只有 CD 和 CE 跨组，cut = 2+1 = 3。两种方案的人数都是 2 与 3，但割代价相差 9。平衡相同不代表连接质量相同。试着点击下面的节点换侧，观察切边清单随哪一个决定而变化。

03 · 人数、面积与容量

默认每个节点 size=1 时，节点数与面积和相同。把 A 的面积改成 4，就不再如此：ABC 的人数仍是 3，面积却是 6；DE 的人数和面积都是 2。容量 C=4 时，ABC | DE 虽然 cut 只有 3，仍然放不下。

本课程显式报告 counts 和 areas。KL 交换一左一右，保持每侧节点数；如果两点面积不同，交换后面积仍会改变。FM 基础实验也按节点数差约束合法性。多路划分的 capacity 则按面积和检查。读一项“平衡”结论时，必须同时读它使用的量和阈值。

若总面积为 S、每组容量为 C，那么至少需要 ceil(S/C) 个组。这是必要条件，不是一般的充分条件。例如面积 3、3、3 放进两个容量 5 的组，总容量 10 大于总面积 9，但任何两个节点都无法同组，实际上需要三个组。

04 · 两个平衡指标

对二分的面积 s0、s1，本课程使用 ratio = min(s0,s1)/max(s0,s1)，越接近 1 越均衡；imbalance = |s0−s1|/(s0+s1)，越接近 0 越均衡。公共图 2 对 3 的 ratio 为 2/3，imbalance 为 1/5。它们数值不同，不能用同一阈值互换。

空组会得到 ratio=0，但我们仍把它标成不可行。指标函数既返回数值，也返回 nonempty 与 feasible。这样可以保留诊断信息，同时避免把“cut=0”的全塞一侧方案误判为优秀答案。

对 k 路，页面仍显示各组面积，以及最小/最大面积比和极差/总面积。这里是教学用的描述量，不把它冒称为论文里任何一种归一化 cut。比较两个结果前，先确认 k、面积定义和容量一致。

05 · 先判合法，再谈目标

优化问题包含目标和约束。目标是减小 cut；约束是完整互斥、非空和约定的平衡或容量。先在合法解集合中筛选，再比较目标。把非法方案与合法方案混排，会奖励规避约束的结果。

若两个合法方案 cut 相同，可以进一步报告面积分布，但不要悄悄加入一个未声明的新目标。后续算法的平票规则都明确写出，例如同增益时按节点名排序。这能保证课堂演示、练习答案和自动测试可复现。

本章是评价器，不会自动寻找最优划分。下面实验中的节点换侧由你决定；算法章节才会产生候选与自动决策。小图精确枚举可帮助校准，却不能说明一种启发式在大图上也总能找到最优。

06 · 写一个可靠的评价器

实现时先验证节点唯一、面积为正、边端点存在、权重有效，再验证 assignment 对所有节点给出合法组号。无向图的邻接表常把一条边存两次；若直接遍历邻接表求和，需要去重。本课程规范化后的 edges 列表每条边只有一项，因此直接累加即可。

cost = 0
for u, v, w in edges:
    if assignment[u] != assignment[v]:
        cost += w

用三个性质检查实现：交换组号不会改变 cut；所有边权乘 c 后 cut 也乘 c；在固定分组下，把一条跨边权重增加 Δ，cut 恰好增加 Δ。这样的检查比只记住 G01 的答案更能发现错误。

07 · 带着契约进入下一章

接下来先构造初始二分，再用 KL/FM 改进，随后学习谱排序、递归二分和多路比较。每种方法输出不同的决策过程，但都回到本章的评价器。实验台允许回退到任一事件；指标总是对应当前图上显示的分组。

完成本章时，你应能解释一个 cut 来自哪些边，指出当前平衡按人数还是面积计算，并拒绝一个低 cut 却违反容量的方案。请先做挑战题，再到 Python 区实现 cut_cost 与 group_loads；通过检查后，页面会显示你自己的函数算出的结果。

08 / COMMON MISTAKES

这些结论需要再想一步

cut 小就一定好

全放同侧 cut=0，但空组或超容量会让方案不可行。先检查约束。

人数等于面积

A 面积从 1 变为 4 时，ABC 人数仍 3，面积变为 6。

每条无向边算两遍

G01 每边一次时 cut=3，重复计算会错误得到 6。

总容量够就一定可行

面积 3、3、3 无法放进两个容量 5 的组。
