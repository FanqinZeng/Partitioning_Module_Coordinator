03 / BEFORE YOU READ

先认识这些词

把连接紧密的节点拉近，怎样得到一条可切开的队列？

拉普拉斯 / Laplacian

L=D−A，D 是加权度的对角矩阵。

Fiedler 向量

与第二小特征值对应的特征向量。

残差 / residual

‖Lx−λx‖/‖x‖，检查数值求解质量。

扫描 / sweep

按特征向量值排序，逐个前缀试切。

简并 / degeneracy

相关特征值相等，向量方向不唯一。

01 · 用全图结构产生排序

谱方法先把离散分组问题放松成连续坐标问题，让强连接节点的坐标更接近，再把坐标转回分组。本课程使用未归一化拉普拉斯 L=D−A，矩阵按输入节点顺序排列；它不是归一化割算法，也不是屏幕中的物理弹簧模拟。

若 x 是节点坐标，xᵀLx=Σ边 w(u,v)(xu−xv)²。权重大而坐标差大的边会带来大能量。常量向量能量为 0，却没有分组信息，所以需要排除常量方向，并固定向量长度，避免用全零解取巧。

02 · 逐边构造矩阵

对边 u–v、权重 w，在 Luu、Lvv 加 w，在 Luv、Lvu 减 w。公共图中 A 的加权度为 6，所以第一行按 A…E 顺序是 [6,−5,−1,0,0]。每行和为 0，矩阵对称，对角线非负。

for each edge (u,v,w):
    L[u,u] += w; L[v,v] += w
    L[u,v] -= w; L[v,u] -= w

若把无向邻接表里的两份边都累加，矩阵会整体加倍；虽然某些排序可能不变，特征值与能量已经变了。先核对建模与矩阵，再看最终切割结果。

03 · Fiedler 向量与数值诊断

将特征值从小到大排列。连通图的最小值为 0，对应常量向量；第二小值 λ2 对应的向量称为 Fiedler 向量。页面使用对称 Jacobi 旋转实时求解，同时报告 ‖Lx−λ2x‖/‖x‖、与常量方向的内积及 λ2、λ3 的间隙。

向量 x 与 −x 都合法，翻号只会反转排序方向、交换左右命名。为使结果稳定，本实现让按名称第一个显著非零分量为正。接近相等的分量和平票还需要确定性规则；数值误差不能靠手写一个好看的顺序掩盖。

04 · 扫描，而不是只切正负号

将节点按向量值升序排列，依次尝试前 1、2…n−1 个节点作为左侧。对每个切口先检查人数窗口，再计算 cut。默认要求每侧至少占 20%；这个比例按节点数计算，界面不会把它称为面积约束。

G01 的排序为 E、D、C、B、A，四个前缀的 cut 为 6、3、5、6。最佳前缀长度为 2，得到 DE | ABC。机械地从序列中间切，或只按正负号切，可能错过更低的合法 cut。

05 · 断连与重复特征值

图有多个连通分量时，零特征值也有多个，第二特征向量不唯一。即使图连通，若 λ2=λ3，也可能有多个同样合法的方向。例如四节点等权环的 λ2 与 λ3 都为 2。不同求解器可能给出不同向量，不能仅凭符号或逐项值不同就判错。

诊断区会显示这些警告。检查应结合残差、合法性、能量与最终目标；对非唯一解，不强行要求与某张截图相同。若窗口没有任何合法前缀，引擎报告 infeasible，不用一个违规的中间切口代替。

06 · 松弛不保证离散最优

连续坐标只是一种结构提示。排序前缀仅覆盖很小一部分二分，最后还要施加离散和平衡约束。谱二分在 G01 上得到最优 cut=3，不表示它在所有图上全局最优。

小图可以枚举全部合法二分进行对照。若谱结果比精确解大，这不是自动说明数值求解错了；先检查矩阵、残差和约束，再判断它是否只是松弛与舍入造成的差距。

07 · 实现两个可审查的环节

Python 区实现 laplacian 和 sweep_cut。前者验证矩阵结构，后者接受明确的节点顺序与人数窗口，返回最佳合法前缀对应的分组。它把数值求解与离散扫描分开，便于分别测试，不要求学生在入门练习中重写整个特征分解器。

下一章会在每个当前分组的诱导子图上重新构造矩阵和排序。不能把全图 Fiedler 顺序裁剪一下，就假装已经重新求解了不同的子问题。
