Foundations

The graph, formulas and contracts shared across the course.

G01

V={A,B,C,D,E}; E={AB:5, AC:1, BC:4, CD:2, CE:1, DE:5}; size(v)=1.

The shared evaluator

cut = Σ w(u,v) [part(u) ≠ part(v)]
area[p] = Σ size(v), part(v)=p
ratio = min(area) / max(area)
imbalance = (max(area) − min(area)) / Σ area

Count every undirected edge once. Assign all vertices exactly once; target parts must be nonempty. Capacity uses area. KL fixes side counts, basic FM uses count difference, and spectral sweep uses count fractions.

Prerequisites

You need weighted graphs, sums, arrays and functions. The spectral lesson explains matrices and eigenvectors; exploring the lab can precede the derivation.

Important distinctions

Construction produces a start; refinement modifies it. Trial states can worsen; accepted states follow the prefix rule. A local stop is not a global proof. Check feasibility before rewarding a low cut.
