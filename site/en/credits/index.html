What this integration changes

The course unifies bilingual lessons, a shared graph and metrics. KL/FM run full passes with locks and rollback. Recursive bisection solves induced subgraphs live. Swap refinement is distinguished from full FM. New features include embedded labs, comparison, 49 feedback challenges, browser Python, search and portable progress.

Design, code and production guidance

Learning Clustering · Su3037 provides MIT graph utilities, KL/FM/spectral engines and base styles, plus the CC BY 4.0 course-playbook. This course preserves notices and adds adapters, validation and new interfaces.
