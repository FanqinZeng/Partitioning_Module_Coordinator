Progress and privacy

Progress and drafts stay in this browser; there is no account, cloud sync or grade upload. Mark reading manually. Reach the last lab step, answer challenges correctly and pass code checks to complete those activities. Export before clearing browser data.

Offline learning

Download and extract the site bundle, run its serve.py local server, then open the printed URL. The homepage introduction, lesson films, lessons, search, labs and Python use local files; author-hosted films and external links still need a connection. Opening HTML directly can block modules and workers.

Download offline course ↓ · Download all Python exercises ↓

Keyboard and accessibility

Use Tab for controls and forms. Enter or Space moves an interactive vertex. Playback and timeline controls support the keyboard. / opens search; Escape closes it. Reduced-motion preferences disable transitions; automatic stepping starts only when you press Play.
