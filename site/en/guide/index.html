LEARNING PARTITIONING / GUIDE

Site guide

Choose a course and try your first experiment. Each step takes you straight to the feature.

Your first visit

  1. 01

    Choose a course

    Use the learning map to choose a course. To learn cut cost and grouping, open Partitioning and start with Lesson 02. Switch languages using EN or 中文 at the top of the page.

    View the learning map →
  2. 02

    Watch and try

    Open the Lesson 02 film and press Play. It pauses twice. Use the panel below the player to predict the cut or move vertices and check capacity. Read the feedback, then select Continue watching.

    Open the interactive film →
  3. 03

    Test an idea in the lab

    Select a vertex in the lab to move it and watch how crossing edges and cut cost change. Submit an answer in Challenges and open a hint if you get stuck. Use Python to run the code checks in your browser.

    Open the lab →Try the challenges →Open Python →
  4. 04

    Compare results and pick up later

    Run several algorithms on the same input in Compare. Use Copy comparison link to recreate an experiment. Open Progress to check completed activities or export your record.

    Open comparison →View your progress →

Looking for a concept? On a lesson page, select the search icon or press / to search the lesson text. The Guide & offline learning link in the footer brings you back here.

Progress and privacy

Progress and drafts stay in this browser; there is no account, cloud sync or grade upload. Mark reading manually. Reach the last lab step, answer challenges correctly and pass code checks to complete those activities. Export before clearing browser data.

Offline learning

Download and extract the site bundle, run its serve.py local server, then open the printed URL. The homepage introduction, lesson films, lessons, search, labs and Python use local files; author-hosted films and external links still need a connection. Opening HTML directly can block modules and workers.

Download offline course ↓ · Download all Python exercises ↓

Keyboard and accessibility

Use Tab for controls and forms. Enter or Space moves an interactive vertex. Playback and timeline controls support the keyboard. / opens search; Escape closes it. Reduced-motion preferences disable transitions; automatic stepping starts only when you press Play.
