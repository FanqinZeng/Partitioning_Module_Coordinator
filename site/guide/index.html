LEARNING PARTITIONING / REFERENCE

使用指南

按自己的节奏阅读、预测、实验和编程。

推荐学习方法

  1. 先读目标与术语，确认本章的输入和约束。
  2. 在随文实验中先预测下一步，再运行和回退。
  3. 完成计算、预测和诊断三类挑战；需要时逐级打开提示。
  4. 实现两个 Python 函数，通过命名检查并解释自己的输出。

学习记录与隐私

记录仅保存在当前浏览器，包括代码草稿；没有账号、云同步或成绩上传。阅读需手动标记，实验到达最后一步、挑战答对、代码全部检查通过才分别记录。清理浏览器会删除本地记录，建议定期导出。

离线学习

下载站点包后解压，用包内 serve.py 启动本地服务器，再在浏览器打开。首页导论片、实验、讲义、搜索和 Python 都使用本地文件；作者托管的原影片与外链仍需网络。直接双击 HTML 会受到浏览器模块与 worker 的限制。

键盘与可访问性

Tab 导航到按钮和表单；节点换侧支持 Enter/空格；播放、回退与时间轴可用键盘操作。按 / 搜索，Esc 关闭搜索。系统的减少动态设置会关闭界面过渡；算法只在你按播放后自动前进。
