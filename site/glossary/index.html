LEARNING PARTITIONING / REFERENCE

术语表

中英术语与可回到上下文的解释。按 / 也可以搜索讲义全文。

节点 / vertex
电路单元；带有正的面积 size。 Lesson 02 ↗
边权 / weight
一次跨组连接的非负代价；本实验要求正权。 Lesson 02 ↗
割代价 / cut
所有跨组无向边的权重之和，每条只算一次。 Lesson 02 ↗
容量 / capacity
每个分组所容许的最大面积和。 Lesson 02 ↗
可行 / feasible
满足完整分组、非空与规定容量。 Lesson 02 ↗
构造 / construction
从没有分组开始建立分组。 Lesson 03 ↗
种子 / seed
控制伪随机序列的整数。 Lesson 03 ↗
增量 / increment
当前决定对已分配节点造成的新跨边代价。 Lesson 03 ↗
区域生长 / region growing
从一个锚点逐步吸收连接最强的未选节点。 Lesson 03 ↗
平票 / tie
分数相等时采用预先声明的确定性规则。 Lesson 03 ↗
D 值 / D value
节点跨组边权减同组边权。 Lesson 04 ↗
增益 / gain
cut_before − cut_after，正数表示改进。 Lesson 04 ↗
锁定 / lock
本 pass 中不再选择已试探的节点。 Lesson 04 ↗
pass
从初始状态开始，选择互不重复的候选直到无法继续。 Lesson 04 ↗
最佳前缀 / best prefix
累计增益最大的最早前缀，允许空前缀。 Lesson 04 ↗
合法候选 / legal move
移动后两侧非空，节点数差不超过 maxDiff。 Lesson 05 ↗
FS
一条 net 在节点原侧的 pin 数。 Lesson 05 ↗
TE
一条 net 在目标侧的 pin 数。 Lesson 05 ↗
gain bucket
按增益值组织候选；本实现用 Map 并扫描合法节点。 Lesson 05 ↗
回退 / rollback
撤销最佳前缀之后的所有试探。 Lesson 05 ↗
拉普拉斯 / Laplacian
L=D−A，D 是加权度的对角矩阵。 Lesson 06 ↗
Fiedler 向量
与第二小特征值对应的特征向量。 Lesson 06 ↗
残差 / residual
‖Lx−λx‖/‖x‖，检查数值求解质量。 Lesson 06 ↗
扫描 / sweep
按特征向量值排序，逐个前缀试切。 Lesson 06 ↗
简并 / degeneracy
相关特征值相等，向量方向不唯一。 Lesson 06 ↗
诱导子图 / induced subgraph
保留指定节点以及两端都在其中的边。 Lesson 07 ↗
叶子 / leaf
当前仍作为一个分组的子问题。 Lesson 07 ↗
分裂树 / split tree
记录每个父组如何产生两个子组。 Lesson 07 ↗
新增割 / added cut
一次分裂导致的全图 cut 增量。 Lesson 07 ↗
局部约束 / local constraint
只作用于当前二分，未必保证所有最终组的容量。 Lesson 07 ↗
k 路 / k-way
把节点划分到 k 个互斥非空组。 Lesson 08 ↗
轮转 / round robin
第 i 个节点分到 i mod k。 Lesson 08 ↗
交换改进 / swap refinement
每步执行一个严格正增益且容量合法的跨组交换。 Lesson 08 ↗
局部最优 / local optimum
当前邻域中没有改进，不等于全局最优。 Lesson 08 ↗
精确枚举 / exact oracle
小图枚举全部合法分组，用于校准与验证。 Lesson 08 ↗
